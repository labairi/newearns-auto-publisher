You can password protect a PDF in a few minutes with Adobe Acrobat, Preview on a Mac, Microsoft Word or an online tool. Before you start, decide which kind of password you need. One stops people opening the file at all. The other only limits printing, editing and copying, and the two protect very different things. This guide gives the steps for each method, then covers the limits that most tool pages leave out.

If you only need to stop the wrong person reading a file, any method that sets an open password will do. If you also want to limit printing or editing, use Acrobat desktop or Preview, and read the section on what restrictions can and can't do before relying on them.

Open password vs permissions password

  • Open password (also called a user password): anyone who wants to view the file has to type it. In Acrobat this is the Viewing option under Protect with password, according to Adobe Experience League.
  • Permissions password (also called an owner password): controls whether people can print, make changes or copy content. Preview calls it the "Owner Password" and lets you choose which actions are allowed without it, per Apple's Preview guide. Adobe describes Acrobat's Restrict Editing like this: "Anyone can open and view the file, but they need to know the password to make any further edits to the PDF" (Adobe Acrobat hub).

You can set both on one file. In Preview, the owner password can be the same as or different from the open password (Apple). Using two different passwords lets you share the open password with a client without also giving them the password that changes the restrictions.

How to password-protect a PDF in Adobe Acrobat (desktop)

These steps follow Adobe Experience League's current Acrobat desktop guide. Menu labels may differ in older Acrobat versions. Some older Adobe pages describe a Tools > Protect path instead.

Set a password to open the file

  1. Open the PDF in Acrobat and choose All tools > Protect a PDF.
  2. Select Protect with password.
  3. Choose Viewing.
  4. Enter the password, re-type it, and select Apply. A confirmation message appears.

You can't add passwords to a document that has been signed or certified (Adobe Experience League). If you need both, add the password before the file is signed.

Restrict printing, editing and copying

  1. In the Protect a PDF tools, choose Encrypt with Password, then select Yes to confirm.
  2. Select Restrict editing and printing of the document.
  3. Set Printing Allowed (for example, High Resolution) and Changes Allowed (for example, None).
  4. Enter a permissions password. Acrobat shows how strong it is.
  5. Choose a compatibility and encryption option, then select OK.
  6. Re-enter the password when asked, then Save the file.

Source: Adobe Experience League. On the encryption choice: the qpdf documentation recommends AES, and 256-bit AES in particular, so avoid options that would fall back to older 40-bit or RC4 encryption if your version lists them.

Check it worked

Press Ctrl+D (Windows) or Cmd+D (Mac) and open the Security tab to see what protection the file has (Adobe Experience League). It's also worth closing the file and reopening it to confirm the password prompt appears before you send it to anyone.

How to password-protect a PDF on a Mac with Preview

Apple documents these steps in its Preview user guide:

  1. Open the PDF in Preview and choose File > Export.
  2. If you want to keep the original without a password, type a new name. Preview saves a protected copy and leaves the original as it was.
  3. Click Permissions.
  4. To require a password to view the file, select Require Password To Open Document and enter the password.
  5. Use the checkboxes to choose which actions, such as printing or making changes, are allowed without the owner password. Leave an action unchecked to require the owner password for it.
  6. Enter and verify an Owner Password. It can be the same as the open password or different.
  7. Click Apply, then Save.

Apple notes: "Changes take effect the next time the PDF is opened." To change the options or the owner password later, choose File > Edit Permissions (Apple).

How to add a password when saving a Word document as PDF (Windows)

Microsoft's instructions apply to Word for Microsoft 365, Word 2024, 2021, 2019 and 2016, among other Office apps (Microsoft Support):

  1. If the document has been saved before, choose File > Save a Copy. If it hasn't, choose File > Save As or Save a Copy.
  2. Select Browse and choose PDF as the file type.
  3. Select More Options, then Options.
  4. Tick Encrypt the document with a password and select OK.
  5. In the Encrypt PDF Document box, type the password, re-enter it, and save.

This sets an open password; it is the only password option Microsoft documents on that page. A note on other guides: Adobe's hub article lists File > Info > Protect Document > Encrypt with Password under securing a PDF with Word. That path is Word's own document encryption, so it protects the Word file. To put a password on the exported PDF, use the export option above.

Using an online tool

Adobe's free online tool works like this, per Adobe's password-protect page:

  1. Select a file, or drag and drop it onto the page.
  2. Enter a password and re-type it. The tool rates it as weak, medium or strong.
  3. Select Set password.
  4. Download the protected file, or sign in to share it.

Think about where the file goes. Adobe says: "Your file will be securely handled by Adobe servers and deleted unless you sign in to save it" (Adobe). For contracts, invoices with bank details or ID scans, decide whether you're comfortable uploading the file, or use Acrobat desktop, Preview or Word instead.

If you have an Acrobat account, you can also sign in at acrobat.adobe.com and choose Edit > Protect a PDF. Only a view (open) password can be set on the web (Adobe Experience League).

Another option is Private PDF Editor, a browser-based PDF toolkit with about 30 tools, including Protect and Unlock. Standard PDF editing runs in the browser; some conversions are handled differently and have separate disclosures, so check how the Protect tool handles your file before using it for anything sensitive. It has paid plans; see its pricing page for current prices.

What a PDF password doesn't protect

Print, edit and copy restrictions depend on the reader app

The qpdf documentation explains that the open and owner passwords unlock the same encryption key, so "the security of the restrictions placed on PDF files is solely enforced by the software." Software can be modified to ignore those restrictions, and the PDF specification is clear about this (qpdf). Treat restrictions as a polite request that compliant apps honour. If someone must not see the content, don't send it to them; an open password only keeps out people who don't have it.

Older encryption settings are weak, so choose 256-bit AES

As of its last review in 2022, the qpdf documentation says 40-bit encryption can be easily brute-forced whatever the password, and 128-bit encryption with RC4 is insecure. It recommends AES, and if you use AES, 256-bit. It also notes that with 256-bit encryption, leaving the owner password blank effectively makes the restrictions useless, so set an owner password if you want restrictions at all.

The password is only as safe as the way you send it

The UK Information Commissioner's Office advises long, complex passwords and sending the password by a separate channel, for example by phone once delivery is confirmed. It is direct about the common mistake: "Do not include the password within the same email as the encrypted file attachment" (ICO). The same ICO guidance notes that recipients need compatible software to open encrypted files, and it describes a £120,000 fine issued to Surrey County Council, under the previous data protection regime, after misdirected emails that included an unencrypted, unprotected file (ICO).

A practical routine for freelancers: email the protected PDF, then text or call the client with the password. If the file is too large to email, see how to compress a PDF for email.

A lost password can't be recovered

Adobe states: "Your password is not stored anywhere and cannot be retrieved if lost or forgotten." It suggests using a memorable password or a password manager (Adobe Experience League). Keep an unprotected original somewhere safe, such as encrypted storage you control, and send only the protected copy. Preview's option to export under a new name makes this easy (Apple).

Hidden information stays in the file unless you remove it

A password doesn't clean the document. Anyone who opens it can still find metadata and other invisible content. Acrobat has a Remove Hidden Information option that erases potentially identifying invisible data (Adobe Acrobat hub). Run it before you add the password; its exact location may vary by Acrobat version.

Saving as PDF alone doesn't stop editing

Microsoft points out that many programs, Word included, can open and edit PDFs: "Simply sharing something as a PDF is not sufficient to guarantee the recipient can't edit the file" (Microsoft Support). If a quote or contract must not be altered, keep your own original copy as the reference version.

Choosing a password you can actually share

You'll often be reading the password out over the phone, so it needs to be strong and easy to say. The UK National Cyber Security Centre recommends combining three random words, which it says creates passwords that are "'long enough' and 'strong enough' for most purposes." It also suggests a password manager to create and remember strong passwords, and says writing a password down is OK if you keep it somewhere safe (NCSC).

  • Use a different password for each client or file, so one leak doesn't expose everything.
  • Avoid the client's name, the project name or the date. Those are easy to guess.
  • Check the strength meter: Acrobat desktop and Adobe's online tool both rate the password as you type (Adobe Experience League, Adobe online tool).

FAQ

Why won't Acrobat let me add a password?

The file may be signed or certified. Adobe says you can't add passwords to a signed or certified document (Adobe Experience League). Add the password to an unsigned version instead, before it goes out for signature.

Why can I only set an open password in Acrobat online?

That's expected. Acrobat on the web only lets you set a view password (Adobe Experience League). Use Acrobat desktop or Preview if you need printing or editing restrictions.

How do I change or remove a PDF password?

In Acrobat desktop, use Remove security in the left-hand pane (Adobe Experience League). Adobe's online tool FAQ says the owner can remove the password with an Acrobat Pro subscription or 7-day free trial (Adobe). In Preview, choose File > Edit Permissions to change the protection options or the owner password (Apple). For removing protection from your own files in a browser, Private PDF Editor also includes an Unlock tool.

Can I recover a forgotten PDF password?

Not through Acrobat. Adobe says the password isn't stored anywhere and can't be retrieved if lost or forgotten (Adobe Experience League). That's why keeping an unprotected original in a safe place matters.

Should I compress a PDF before or after adding a password?

As a workflow, compress first and add the password last, so the file you actually send is the protected, final version. Our guide on compressing a PDF for email covers the first step.

Which encryption should I pick?

Adobe names 128-bit and 256-bit AES as common encryption types (Adobe). The qpdf documentation recommends 256-bit AES and calls 40-bit and RC4 options weak (qpdf).
